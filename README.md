## Попередній проєкт — шкільний розклад

Навчальний проєкт шкільного розкладу та приклад роботи з API для транскрипції й конспектування аудіо.

Навчальний сайт із розкладом, оцінками, особистими записами та коментарями. Дані зберігаються в SQLite та залишаються після оновлення сторінки й перезапуску Python.

## Запуск

Для запуску розкладу потрібен Python 3; додаткові Python-бібліотеки не потрібні. Залежності окремого аудіоскрипта наведені нижче.

```powershell
python run.py
```

Відкрий **http://127.0.0.1:8000/**. Для зупинки сервера натисни **Ctrl+C**. Якщо команда `python` не працює, спробуй `py -3 run.py`.

Інший порт: `python run.py --port 8001`. Сайт і API працюють на цьому комп’ютері. Сервер запускай через `run.py`: простий статичний сервер тепер не підтримує збереження даних.

## Режим викладача

- Натисни **«+ Додати заняття»** або **«+ Заняття»** під потрібним днем.
- Вкажи дату, клас, предмет, тему, час, номер уроку, кабінет або онлайн-формат.
- Натисни картку заняття, щоб **редагувати** або **видалити** його.
- Зміна або видалення стосуються лише цієї дати. Інші тижні залишаються без змін.
- Заняття можна додати й на вихідний. Такий день з’явиться у тижневому розкладі.
- У вікні заняття постав кожному учню оцінку **від 1 до 12** і, за бажанням, коментар до оцінки. Натисни **«Зберегти оцінки»**.
- Щоб прибрати оцінку, очисть її поле та збережи форму.

## Режим учня

Обери **«Учень»**, клас і демонстраційний профіль.

- Відкрий заняття, щоб побачити **свою оцінку** та коментар викладача.
- У полі **«Мій запис»** запиши особисті нотатки й натисни **«Зберегти запис»**. Вони не з’являються у спільному обговоренні.
- У розділі коментарів постав запитання або залиш відгук. Його бачать викладач і учні цього класу.
- Свій коментар можна редагувати та видаляти. Коментарі інших учнів залишаються для читання.

## Навчальні профілі

У прикладі є 10 класів і по 3 демонстраційні профілі на клас: «Учень 1», «Учень 2», «Учень 3». Це перемикання профілів для навчання, а не справжній вхід з паролями.

API перевіряє поточну роль, клас і власника запису: учень не може через учнівський запит змінювати заняття або оцінки. Оскільки демонстраційний профіль можна вільно перемикати, ці перевірки не замінюють справжньої автентифікації. Для реальних особистих даних потрібен окремий захищений вхід.

## Де зберігаються дані

- `seed.json` — початковий тижневий шаблон, класи й демонстраційні учні.
- `data/schedule.sqlite3` — збережені зміни занять, оцінки, записи та коментарі. Створюється автоматично.
- Тижневий шаблон повторюється, а збережена зміна має пріоритет лише на свою дату.
- Видалене заняття приховується позначкою: пов’язані оцінки та записи не стираються з бази.
- Для резервної копії зупини сервер і скопіюй файл бази. Не видаляй папку `data`, якщо хочеш зберегти свою роботу.

## Структура проєкту

| Файл | Призначення |
| --- | --- |
| `index.html` | Структура сторінки й форми |
| `styles.css` | Оформлення та адаптація для телефона |
| `schedule.js` | Перегляд розкладу, форми та звернення до API |
| `audio-summary.js` | Вибір запису, перевірка та копіювання конспекту |
| `run.py` | HTTP-сервер, публічні файли й обробка запитів |
| `API/audio_service.py` | Нарізка аудіо та запити до моделей |
| `server.py` | Правила ролей, операції з уроками, оцінками, записами та коментарями |
| `seed.json` | Початкові уроки, класи та профілі |
| `schema.sql` | Структура нової бази SQLite |
| `tests/test_api.py` | Перевірки функціоналу в тимчасовій базі |

Сервер віддає браузеру лише публічні файли. SQLite-база, Python-код і службові файли через сайт не завантажуються.

## Як змінювати код

Після зміни HTML, CSS або JavaScript збережи файл і онови сторінку. Якщо бачиш старий вигляд, натисни **Ctrl+F5**. Після зміни Python або `seed.json` перезапусти сервер.

Зміна `schema.sql` сама по собі не перебудовує наявну базу: структуру існуючих даних змінюють окремою міграцією. Не стирай базу, щоб застосувати зміну.

Усі користувацькі тексти відображаються як текст. Функція `h()` у JavaScript не дозволяє введеному HTML виконуватися у сторінці.

## Перші вправи

1. Додай заняття на суботу й знайди його в переглядах дня та тижня.
2. Зміни тему одного уроку й перевір, що наступний тиждень залишився без змін.
3. Постав двом учням різні оцінки. Перемкни профіль і перевір результат.
4. Зроби особистий запис, онови сторінку й відкрий заняття знову.
5. Додай коментар від одного учня та прочитай його від іншого.
6. Зміни основний колір у `styles.css`.
7. Знайди в `server.py`, як перевіряється роль перед збереженням оцінок.

## Перевірка

```powershell
python -m unittest discover -s tests -v
```

Тести використовують окрему тимчасову базу й не змінюють навчальні дані.

## Аудіо → текст → конспект

`API/transcribe.py` — окремий консольний приклад. Він пропонує вибір OpenAI або Groq, отримує шлях до аудіофайлу та зберігає транскрипт і конспект поруч із ним. Для конспекту на сайті використовуються окремі інтерфейс і API у режимі учня.

```powershell
python -m pip install -r API/requirements.txt
python API/transcribe.py
```

Ключ можна задати локально через `OPENAI_API_KEY` або `GROQ_API_KEY`; якщо змінна не задана, програма запитає ключ прихованим введенням. Для обробки аудіо через Groq потрібен `ffmpeg` у PATH. API-запуск використовує ваш обліковий запис і його тариф. Під час підготовки репозиторію API не запускався.

У репозиторії є лише демонстраційні профілі. Запис заняття, збережена локальна база, ключі й результати транскрипції сюди не входять.

### Конспект на сайті

У режимі учня обери аудіозапис, прослухай його, підтвердь вибір і натисни **«Створити конспект»**. Запис ділиться на фрагменти до 8 хвилин. Для транскрипції доступні OpenAI Whisper і GroqCloud Whisper; для конспекту — GPT-5.6-Luna, GPT-OSS-120B та GPT-OSS-20B. Результат з’являється в редагованому текстовому полі з кнопкою копіювання.

Сайту потрібні FFmpeg та ffprobe у `PATH`, а серверу — змінні середовища `OPENAI_API_KEY` та/або `GROQ_API_KEY`. Ключі не передаються браузеру. Файл надсилається вибраним сервісам лише після підтвердження й запуску обробки; завантаження обмежене 300 МБ.
